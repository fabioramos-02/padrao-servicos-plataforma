# Padrão de formulário

O padrão de formulário já está definido no
[Estudo de Formulários](https://fabioramos-02.github.io/estudo-formularios/). **Ele é a fonte**: este guia só
aponta para lá.

Pergunta que guia tudo: *isso deixa o formulário mais fácil de preencher?*

## O essencial

| Regra | Onde está |
|---|---|
| Uma coluna só; campos do mesmo assunto juntos | [Diagramação](https://fabioramos-02.github.io/estudo-formularios/01-diagramacao/) |
| Rótulo claro, em linguagem simples; nome técnico padronizado | [Nomenclatura](https://fabioramos-02.github.io/estudo-formularios/03-nomenclatura/) |
| Mesmo campo, mesmo nome e mesma máscara em todo serviço | [Dicionário de campos](https://fabioramos-02.github.io/estudo-formularios/03-nomenclatura/#35-dicionario-de-campos-canonicos) |
| A régua para conferir | [Checklist do formulário](https://fabioramos-02.github.io/estudo-formularios/04-checklist/) |
| Nome, e-mail, telefone e data no modelo do GOV.UK | [Recomendações GOV.UK](https://fabioramos-02.github.io/estudo-formularios/andamento/recomendacoesGOVUK/) |

## Para parecer o mesmo sistema

- Use os componentes do **Design System MS**. Não crie botão, campo ou cor próprios.
- Os campos têm largura de acordo com o dado (CEP curto, endereço longo) e limite de caracteres.
- As mensagens de erro dizem o que fazer, perto do campo.
- O serviço abre com o mesmo cabeçalho e a mesma trilha da carta de serviço.
